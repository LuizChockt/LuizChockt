# Human + Code — identidade visual

Sistema visual dos projetos open source de Luiz Chockt.

## Paleta

- Modo escuro: `#031320`, `#0B2B43`, `#F7FBFF`, ciano `#27D8FF`.
- Modo claro: `#F7FBFF`, `#E0F2FB`, `#102A41`, azul `#007DB5`.

## Aplicação

- Banners vetoriais SVG para tema claro/escuro e largura desktop/mobile.
- Banners traduzidos para inglês e português brasileiro nos READMEs bilíngues.
- Ícones próprios para as três ferramentas Python, com estrutura visual consistente.
- Conteúdo de perfil em primeira pessoa; descrições técnicas factuais.
- Evitar métricas fictícias e imagens externas não confiáveis.

Estes SVGs são adaptações vetoriais da direção visual das artes conceituais. A foto pessoal do GitHub é alterada separadamente nas configurações da conta.
